# 状态与事实追踪规则

## 角色状态卡片格式（每章更新）

为每一个本章登场角色维护以下字段：

| 字段 | 说明 |
|------|------|
| **角色名** | 角色全名 |
| **存活状态** | 存活 / 重伤 / 死亡 / 失踪 / 未知 |
| **当前位置** | 截至本章结束时所在位置 |
| **身份/头衔变化** | 有无新的身份、称号或地位变动 |
| **已知信息** | 该角色目前知道的关键信息（关键词） |
| **不知道的关键信息** | 该角色不知道但读者已知的信息（信息差 = 张力） |
| **当前情绪状态** | 截至本章结束时的主要情绪 |
| **与主角关系** | 一句话描述（含变化方向：↑亲近/↓疏远/→不变/⚡冲突） |
| **身体状态** | 有无受伤、中毒、异变等 |
| **持有物品/能力** | 当前持有的重要物品或已获得/失去的能力 |
| **本章关键行为** | 本章中的重要行为（最多3条） |
| **待回收的伏笔** | 与该角色相关的未解悬念 |

未登场角色直接沿用上一版数据。

### 特别标注区（状态表底部）
- 🔴 **本章死亡角色**（后续绝对不能再活着出场）
- 🟡 **本章新增角色**
- 🟢 **关系重大变化**
- ⚠️ **信息差更新**

末行注明：状态表更新截止章节：第 X 章

## 事实清单格式（每章追加，只增不改）

### 分类与编号规则

每条事实编号格式：`[FX-YY]`（X=章节号，YY=序号）

```
## 第 X 章事实清单

### 🔴 生死事实（最高优先级）
- [FX-01] 谁死亡/重伤？死因？目击者？

### 🟠 物品/能力变动
- [FX-02] 谁获得/失去了什么？

### 🟡 身份/关系变动
- [FX-03] 谁的身份/关系发生不可逆变化？

### 🔵 信息/秘密揭示
- [FX-04] 揭示了什么？谁知道？谁不知道？

### 🟢 伏笔管理
- [新] 本章埋下的新悬念
- [回收] 回收了哪个伏笔（来源：第X章）
- [待回收] 按节奏应回收但未回收的伏笔

### ⚪ 时间线
- 本章时间跨度：
- 累积时间线：
```

### 铁律
- 事实清单**只增不改**——已记录事实不能删除或修改
- 已死亡 = 后续章节绝对不能活着出场
- 每个事实必须编号——方便引用
- 事实清单 + 角色状态表 = 后续章节的硬约束
