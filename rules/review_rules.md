# 审查润色规则

## 一致性审查（最高优先级）

### 角色状态校验（对照状态表逐项）
- 本章是否让已死亡角色以活人身份出场？→ 🔴硬伤
- 角色位置是否与状态表的"当前位置"矛盾？→ 🔴硬伤
- 角色是否使用了不应该知道的信息？→ 🔴硬伤
- 角色是否使用了已失去的物品/能力？→ 🔴硬伤
- 角色关系互动是否与状态表方向一致？→ 🟡软伤

### 事实清单校验（对照累积清单逐项）
- 是否与任何生死事实矛盾？→ 🔴硬伤
- 是否与物品/能力变动矛盾？→ 🔴硬伤
- 时间线是否吻合？→ 🔴硬伤

### 伏笔校验
- 节奏约束中"应回收的伏笔"是否已体现？
- "必须埋设的伏笔"是否已植入？

### 其他一致性
- 角色行为是否符合档案设定的触发机制？
- 角色对话风格是否一致？
- 文风是否与前序章节一致（视角/比喻密度/详略）？

## 去 AI 化规则

### 高频词替换
| AI 高频词 | 替换方向 |
|-----------|---------|
| 不禁 | 删除或用具体动作 |
| 一股（XXX之感）| 直接描述感受 |
| 宛如/仿佛/犹如/像是 | 减少比喻，每段最多1个；严禁连续使用 |
| 映入眼帘 | "看到"或直接描写 |
| 嘴角微微上扬/眼中闪过一丝/心中暗道 | 换成更具体的描写 |
| 极致的/极度的/深深的 | 用具体行为展现程度 |
| 瞳孔骤缩/倒吸一口凉气 | 换新鲜的反应 |
| 散发着/弥漫着 | 直接描写源头 |

### 标点修复
- 紧张场景用句号 → 改感叹号或省略号
- 区分省略号（虚弱/犹豫）和破折号（被打断/声音渐远）
- 不要只用逗号和句号

### 排版检查
- **加粗滥用**：AI 喜欢在情绪词上加粗，人类写作极少这样。除书信/专有名词外删除所有加粗
- **章间重复**：新章禁止复述上章结尾，禁止"承上启下"式总结开头
- **打破第四面墙**：禁止"第X章"、"上文"、"读者可能记得"等元叙述
- **重复描写**：同一事物多次详写→保留最简洁的一次

### 文艺腔套话（必须替换）
- "湿润的茧"/"裹进...里" → "包住了"
- "轮廓像刀刻的" → 删除比喻
- "灯影和黑暗的交界处" → "明暗交界的地方"
- 连续感官描写堆叠 → 保留1-2个

### 润色铁律
- **禁止机械化全局润色**：干脆利落的短句必须原封保留
- **禁止词藻堆砌**：一个名词前不超过2个修饰词
- **拒绝浮夸比喻**
- **简化过度文学化表达**
- 将"告诉型"改"展示型"（"他很紧张"→"指节发白"）
- 句式多样化：简单句不连续超过3句
- 段落长度不要太均匀

## 审查输出格式

| 严重级别 | 含义 |
|---------|------|
| 🔴 硬伤 | 角色状态/事实清单矛盾，必须修复 |
| 🟡 软伤 | 逻辑不严密或人设偏移，强烈建议修复 |
| 🟢 微瑕 | 表达或细节问题，可选修复 |

审查后直接输出修复后的完整正文。
