# 写作与修稿规则（作家手册）

> 起草与修稿共用这一份。次序即优先级：先写活人，再守规则；先修硬伤，再保声线，最后才轻润。
> 规则的用途是防跑偏，不是把句子磨成同一种模板。

## 一、起草心法

- **先写活人。** 开笔前进入视角人物的身体：他此刻看见什么、要什么、怕什么、想遮住什么、愿意付出什么。资料回答"发生什么"，人物回答"怎么发生"。
- **一口气写完作家稿。** 起草时不过清单，不自我审查文气；所有诊断留给修稿。
- **档案是约束，不是语料。** 节拍卡、账本、角色档案只决定能写什么、不能写什么、必须发生什么。除关键台词和专名，禁止沿用其中任何表达、比喻、句式和段落顺序。
- **项目声线优先。** 有 `style.md` 或用户风格要求时，服从项目声线。直给、短句、爽点只是网文默认策略，不覆盖甜文、克制文、古风或文学向的既定气质。
- **网文项目：大白文是默认底子（起草时就用，别指望修稿补救）。** 大白文不是"短句"这么简单，是一种**纹理**：少描写、不解释设定、不铺氛围、句句往前推、贴着人物的大白话——像一个人在跟你讲他碰上的事，不像作者在写景抒情、在旁边解说。感官文艺句、设定来历讲解、establishing 式风景铺陈、"作者解说"式旁白，都不是大白文。**最常见的翻车：先写一段文艺描写，再删掉最露的几句——底子仍是文艺纹理。起草时就压住，判每句只问一句：它在推剧情/处境/人物，还是在显文笔、讲设定、铺气氛？后者删或压成一句大白话。**（本条只适用于网文声线项目，不覆盖文学向/古风等既定气质。）

## 二、视角

- 每个场景先定主视角：正文只能写这个人能看见、听见、误判、猜到或即时感受到的内容。
- 同一场景禁止无标记跳进另一个角色内心；换视角必须拆场或用分隔符。
- 作者知道而视角人物不知道的信息，禁止进旁白；只能通过可见动作、台词、异常和后果让读者自己拼出来。
- 远景旁白只用于转场；关键场景必须落在场内人物的身体、动作、台词和选择上。
- 每个场景要让读者带着一个具体问题往下读（他要做什么？这人哪里不对？危险从哪来？），推进中回答一部分、留下更尖的一个。

## 三、场景发动机

- 关键场景的链条：**目标 → 阻碍 → 选择 → 代价**。目标具体到场内能完成或失败；高张力场景优先用"带代价的成功"或"失败换来新信息"收束。
- 紧张场景之后允许短续场，但续场也有链条：**反应 → 权衡 → 新决定**，新决定自然成为下一场的目标。
- 一个场景结束时，局势、关系、信息、误判、行动计划至少变一样；全都没变的场景删、并或重写。
- 允许安静场面，但安静必须有功能：隐藏信息、制造误判、让关系变近或变远、让危险靠近。
- 连续对话超过 8-12 句时警惕"人物站桩抛信息"：下一段必须出现改变局面的动作或后果。"看了一眼、沉默、手指收紧"只能作微反应，不能反复顶替行动。

## 四、对话

- 重要台词在创作阶段想清三层：说出来的话 / 心里真正的想法（草稿可用【】标注，终稿删除）/ 身体语言。只有转折、试探、压迫、撒谎、拒绝类台词需要三层，功能句直接说人话。
- 一场对话三到五成是直接功能句：命令、拒绝、确认、威胁、报价、事实落地。摊牌、打脸、行动指令优先直给；暧昧、试探、隐瞒允许绕。
- 真实的人会说错话、词不达意。每场关键对话至少一次：打断、答非所问、情绪失控、粗暴直说或行动代替回答。
- 连续两次"现在不能说 / 以后你会懂"式拖延后，第三次必须给出具体事实、代价或行动。
- 每轮关键对话至少推进一项：局势 / 信息 / 关系 / 情绪压力。没推进就压缩。
- ❌ 角色自报性格（"我这人就是心软"）；❌ 旁白解释他为什么这么说；❌ 全员都说得漂亮克制、像作者在发言。

## 五、设定转行为

- **设定只能改变行为，不能替正文解释行为。** 每条硬设定、信息差、性格标签，都必须对应一个动作、台词、沉默、误判、选择或后果。
- "角色不知道某事" → 写成场内效果：说错话、误会对方、追问失败、被人利用、把真相看反。
- "角色不能说某事" → 写成场内动作：改口、反问、岔开、只说一半、说另一个更安全的真话、用行动代替回答。
- 性格在压力下要变形：冷静的人被逼急了会压低声音、删掉半句话、提前动手；善良的人也会迟疑、逃避、撒自以为无害的谎。
- ✅ 可以写：他忽然不想问了。再问下去，答案就不是钱能解决的事。
- ✅ 可以写：江野第一反应是把纸抢回来。手伸到一半，他看见知夏还站在门边。
- ❌ 不要写：他感到一种复杂而难以言说的恐惧。
- ❌ 不要写：她还不知道真相，所以他不能说。

## 六、章节接力（长篇的命脉）

- **新章不是新故事。** 第 2 章起，第一场必须接住接力卡里的压力：上一章未解决的问题、未完成的动作、新闯入的冲突。禁止用天气、地点、身份介绍重新开场。
- 章首环境描写必须有场内功能：阻碍行动、放大危险、暴露身份、制造误判。纯风景铺陈删。
- 每章只推进长链条中的一段，不追求把本章包装成完整短篇。情节目标完成一半也行，只要局势、关系、信息或计划发生明确变化。
- 章末停在链条最有牵引力的位置：新敌人进场、代价落地、误判加深、选择被逼出。跨章钩子来自场内后果，不来自作者预告。
- ❌ 说书式收束：“欲知后事如何”“这一切才刚刚开始”“新的篇章就此展开”。
- ❌ 独立短篇化：开头铺陈—中段完成事件—结尾总结点题。修稿时读出这种结构，拆掉开头说明和结尾总结，把重心改成承接前章压力、制造下章压力。

## 七、情绪与节奏（正文层）

- 情绪来自处境。要读者紧张，就加码、缩时、砍退路；要读者松口气，就兑现一个小胜利。禁止用情绪词堆情绪。
- 心理描写只写视角人物此刻的具体念头、误判、冲动或自我压制，短、准、带选择压力；写完尽快让人物说话或行动。
- 高张力场景里，动作和台词的存在感必须高于环境；短暂留白和压迫感描写可以保留。
- 爽点必须让读者看见"谁做了什么，造成了什么结果"；爽点句短、狠、断，不要用长句把劲卸掉。
- 该爽就爽，该疼就疼。关键情绪不藏过头，避免"意思到了，读者没被戳到"。

## 八、修稿清单（次序即优先级）

### 1. 硬伤（对照账本与故事核，必修）

- 死者以活人身份出场；位置、时间线不可能；已失去的物品或能力被使用。
- 角色说出或用到了他"不知道"的信息；信息差穿帮。
- 底牌越层：埋着的牌被解释，半开的牌被说透，亮牌没付代价。
- 专业硬伤：医疗、法律、警务、金融等流程没有 `research/` 摘要或可靠来源支撑却写得言之凿凿（按 `rules/research_rules.md` 处理）。

### 2. 链条

- 第一场是否接住接力卡；章末是否留下场内压力；中段是否偏离节拍卡的因果链。
- 与节拍冲突且改文能解决 → 改文；改文会破坏更好的现场判断 → 保留正文，在简报里报偏差。

### 3. 人味（资料腔与设定泄漏）

- 规划词进正文即删改：情节目标、情绪强度、核心事件、承接、底牌、信息差、读者期待……
- 总结性解释句改成可见行为："他终于意识到""她确认了他的在乎""这个动作说明了"。
- 出现"因为她还不知道 / 他不能说 / 设定上"等作者推理，改写成第五节的场内动作。
- 关键设定是否通过场景压力释放？先给解释再给场面的段落，调成：异常/动作/台词 → 读者产生判断 → 后果确认。

### 4. AI 味诊断（是诊断，不是禁词表；自然、少见、合声线的不必动）

| 症状 | 处理 |
|------|------|
| **过度描写/解释/铺氛围（大白文项目头号漂移，非坏句而是整段纹理偏文艺）**：感官文艺句（"锈味重到发甜，像铁末在舌根上化开"）、设定来历讲解（"废铁堆了几百年，金气烂在底下，就化成…"）、establishing 式风景铺陈（"洞底比他想的要大，头顶不知多高…"）、"作者在旁解说"式旁白 | 删描写、删解释、删铺垫，只留推进剧情/处境/人物的动作、台词、大白话念头。判每句只问：它在推进，还是在显文笔/讲设定/铺气氛？（仅网文声线项目，文学向不适用） |
| 高频模板词：不禁、一股、宛如、仿佛、犹如、映入眼帘、嘴角微微上扬、眼中闪过一丝、心中暗道、缓缓说道、深吸一口气、瞳孔骤缩、倒吸一口凉气 | 显得模板、重复或空泛时替换成具体动作 |
| 连续否定定义："不是X，是Y""不快不慢、不轻不重" | 一章多次出现即删减，换具体动作或触感 |
| 一个名词挂两个以上形容词；每段一个以上比喻 | 堆砌感明显时压缩 |
| 情绪词加粗、破折号滥用、感叹号连排 | 除书信和专名外删除加粗；标点服从角色声线 |
| 元叙述："上文说到""读者可能记得""（第X章完）""敬请期待" | 一律删除 |
| 段落长度、句式节奏过于均匀 | 保留长短变化、沉默与余韵，不统一成短句流 |
| 论文腔：旁白成段解释推理链、动机、布局原理（"他要的答案很简单：要么……要么……"）；"这说明""他最恨的就是"式总结盖章句 | 压成一两个当下念头或直接删，让行动和后果自己说话；来龙去脉进台词或半句带过 |
| 结构化排比描述："用X——用Y——用Z——"式三连清单、成对工整的例句 | 打乱结构，留一两个最狠的细节，用人物口吻串起来 |
| 文青炫技：警句体收段、悖论花活（"越抖越把话往下顶"）、概念加引号、泛化格言（"跑夜路的人对变化敏感"）、同一喻体反复回收 | 改成视角人物口吻的大白话；喻体全章限一次、跨章不复用（人物台词内不限） |

### 5. 轻润（最后做，轻手）

- 优先局部替换、删冗余、调顺序；禁止机械化全局润色，禁止把整段改成同一种断句节奏。
- 保留有视角、有情绪推进的长句、比喻和留白；删除只展示文笔、不推进冲突/关系/悬念的句子。
- 每段问一句：这段让读者更想看，还是更想跳？后者删或缩。
- 冷读收尾：对照项目基准声线（style.md 指定的基准章，默认最早定调的几章）通读一遍；成片书面语、**描写段、铺氛围段**、解释段、排比清单即为漂移，按第 4 节处理。

### 分级

| 级别 | 含义 | 处理 |
|------|------|------|
| 🔴 硬伤 | 与账本事实、信息差、底牌进度矛盾 | 必须修复后才能出终稿 |
| 🟡 软伤 | 人设偏移、关系跳级、逻辑勉强 | 尽量修；修不动就在简报提示 |
| 🟢 微瑕 | 措辞、称谓、重复描写 | 不伤文气时顺手处理 |

## 九、输出格式

- 直接输出小说纯正文：对话用引号，段落间空行。
- **最高禁令**：正文前后不得附加任何创作说明、对齐说明、预告、"（第X章完）"。结尾落在情节上。
- 审查任务默认直接输出修复后的完整正文；用户明确要报告时才输出审查报告。
