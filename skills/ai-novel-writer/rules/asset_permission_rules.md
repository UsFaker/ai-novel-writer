# 关键资产权限规则

## 核心原则

设定材料不等于可写材料。任何关键物品、核心秘密、力量规则、反派计划、世界真相、主角身世、组织制度、地点机关、关系真相和终局钥匙，都必须先通过 `outlines/全书关键资产库.md` 的权限检查。

若项目存在 `outlines/全书关键资产库.md`，生成章节方向、场景骨架、正文、审查润色和状态更新时，必须读取并遵守它。若项目是百万字级长篇但缺少该文件，禁止继续生成新大纲或新章节，先提示用户执行阶段 0C。

---

## 写前权限检查

每次写作、修改、审查或生成下一章方向前，内部逐项确认：

1. 本章涉及哪些关键资产？
2. 这些资产当前处于哪个解锁阶段：影子、接触、误用、局部揭示、真相、高潮？
3. 当前章节是否允许该资产实体出现？
4. 当前章节是否允许解释该资产的用途、来源、代价或关联势力？
5. 主角是否有权限知道此信息？
6. 读者是否有权限知道此信息？
7. 反派/对立面是否已经知道此信息？
8. 本章是否让资产发挥了超出当前解锁层级的功能？
9. 本章是否把材料里的后期用途提前写成了明确说明？
10. 如果要揭示信息，是否伴随代价、误判、风险、关系变化或新问题？

任一项无法确认时，停止写作，提示缺少资产权限信息。

---

## 前十章信息阀门

前十章只允许建立：
- 主角当前困境。
- 世界的一条可感规则。
- 一个异常物、异常人或异常事件。
- 一个短线危机。
- 一个读者能记住的问题。

前十章禁止解释：
- 全部世界观。
- 完整力量体系。
- 反派全盘计划。
- 主角终极身世。
- 关键物品真正用途。
- 全书最终目标。
- 组织制度完整历史。
- 终局钥匙的正确用法。

如果大纲或正文试图在前十章讲完上述内容，必须改成影子、异常、误判、失败后果或他人忌惮。

---

## 资产解锁层级

### 1. 影子阶段
允许：
- 异常现象。
- 传闻。
- 残片。
- 禁忌称呼。
- 他人忌惮。
- 错误判断。
- 使用后的后果。

禁止：
- 完整来源。
- 真正用途。
- 正确用法。
- 关联终局。
- 反派计划全貌。

### 2. 接触阶段
允许：
- 主角或相关角色接触资产。
- 看见表面用途。
- 产生错误理解。
- 被资产带来麻烦。

禁止：
- 立刻正确使用。
- 立刻说明隐藏用途。
- 让资产解决当前大危机且无代价。

### 3. 误用/误解阶段
允许：
- 错误使用资产。
- 因误判得到短期收益。
- 付出代价。
- 暴露给敌人或引来追索。

必须：
- 造成信息、关系、资源、局势或风险中的至少一项变化。

### 4. 局部揭示阶段
允许：
- 揭示一层真相。
- 解释一条规则。
- 修正一次误判。

必须保留：
- 更深层来源。
- 终局用途。
- 更高层代价。
- 至少一个读者仍想追问的问题。

### 5. 真相阶段
允许：
- 说明真正用途或核心秘密。
- 让主角做出正确选择。

必须：
- 让真相带来新的代价或不可逆后果。
- 改变全书故事宪法中的至少一个不可逆变量。

### 6. 高潮阶段
允许：
- 让资产改变卷高潮或全书高潮局势。

禁止：
- 机械救场。
- 无代价解决根本问题。
- 临时新增从未影子铺垫的终局功能。

---

## 信息释放规则

- 读者知道、主角知道、反派知道必须分开管理。
- 信息不能因为“设定材料里写了”就进入正文。
- 揭示必须通过行动、失败、误判、交易、威胁、死亡、背叛、损坏、选择或后果实现。
- 重大信息揭示后，必须带来一个新问题或新代价。
- 如果某段只是解释资料，没有改变场内局势，必须压缩或改写。

---

## 审查判定

### 🔴 硬伤
- 使用未解锁关键资产。
- 主角提前知道后期真相。
- 前期直接解释关键物品真正用途。
- 让终局钥匙提前发挥终局功能。
- 把反派计划全貌当普通说明讲出。
- 资产持有权与资产库矛盾。

### 🟡 软伤
- 揭示没有代价。
- 资产出现但没有改变局势。
- 物品只像道具，不像剧情压力源。
- 伏笔没有回收窗口。
- 同一章解释多个核心资产，信息过载。

### 🟢 微瑕
- 资产名称前后不统一。
- 解锁描述略模糊。
- 资产与故事线绑定不够清晰。

所有 🔴 硬伤必须修复后才能输出正文或大纲。

---

## 状态更新要求

每章完成后，如果涉及关键资产，必须同步更新：

- 当前持有者。
- 解锁层级。
- 谁知道了什么。
- 谁误解了什么。
- 本章造成的代价。
- 下次允许推进窗口。
- 是否触发禁止提前暴露风险。

建议追加到 `outlines/全书关键资产库.md` 的“资产动态记录”区，或同步写入事实清单的“物品/能力变动”“信息/秘密揭示”“伏笔管理”分类。
