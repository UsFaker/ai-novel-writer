# 审查润色规则

## 一致性审查（最高优先级）

### 角色状态校验（对照状态表逐项）
- 本章是否让已死亡角色以活人身份出场？→ 🔴硬伤
- 角色位置是否与状态表的"当前位置"矛盾？→ 🔴硬伤
- 角色是否使用了不应该知道的信息？→ 🔴硬伤
- 角色是否使用了已失去的物品/能力？→ 🔴硬伤
- 角色关系互动是否与状态表方向一致？→ 🟡软伤

### 事实清单校验（对照累积清单逐项）
- 是否与任何生死事实矛盾？→ 🔴硬伤
- 是否与物品/能力变动矛盾？→ 🔴硬伤
- 时间线是否吻合？→ 🔴硬伤

### 伏笔校验
- 节奏约束中"应回收的伏笔"是否已体现？
- "必须埋设的伏笔"是否已植入？

### 其他一致性
- 角色行为是否符合档案设定的触发机制？
- 角色对话风格是否一致？
- 文风是否与前序章节一致（视角/比喻密度/详略）？

## 小说感与视角审查（高优先级）

### 资料扩写痕迹
- 正文是否能看出方向文档、情绪节拍表或场景素材的句子被扩写？如果能，必须重写为场内行动。
- 是否出现“本章要体现的情绪/关系/设定”被旁白直接说出，而不是由人物动作和后果让读者看见？
- 是否把规划词写进正文，例如“剥离、终局感、情绪强度、核心事件、读者期待、承接点”等？出现即删除或改写。
- 是否大量使用“他终于意识到/她确认了/这个动作说明了/这意味着”等总结性解释？必须换成角色当下能看见的行为。
- 是否保留了场景素材中的半成品句子、氛围句、结尾句？除关键台词外，不得直接沿用。

### 设定泄漏与创作判断
- 是否在正文中出现“因为设定/状态表/大纲要求/她还不知道/他不能说/他不会这么说”这类作者推理？出现即为资料泄漏，必须改成场内动作、台词、沉默、误判或后果。
- 角色是否像在执行设定标签，而不是像一个有欲望、有压力、有遮掩策略的人？如果是，必须补出表层目标、真实动机、压力来源和选择代价。
- 信息差是否只被旁白解释，而没有造成误会、回避、追问、试探、误导、关系变化或行动后果？没有后果就必须重写。
- 性格设定是否被写成固定模板，例如“冷静的人永远冷静”“善良的人永远正确”“聪明人永远不犯错”？必须改成压力下的具体变形。
- 角色“不说某事”的处理是否只是空白或作者说明？必须写清他如何避开：改口、反问、岔开、行动代替回答、说半句、说另一个更安全的真话。
- 每个关键场景结尾是否有不可逆变化：局势、关系、信息、误判、行动或代价至少推进一项。若没有，说明场景只是在摆资料，必须压缩或重写。

### 视角与读者体验
- 每个场景的主视角是否清楚？读者是否知道自己站在谁的感知里？
- 同一场景是否跳进了多个角色的内心？如有，拆场或改成外部可见反应。
- 读者问题是否存在并推进：开头让读者问什么，中段加深什么，结尾回答/反转/留下什么？
- 是否先给解释再给场面？正确顺序应是：异常/动作/台词 → 读者产生判断 → 后果确认。
- 关键设定是否通过场景压力释放，而不是旁白一次性讲清？

### 句式腔与说明腔
- “不是X，是Y”可以偶尔用于强调，但连续出现两次以上就会显得像模板推理，必须改成具体动作、触感、台词或后果。
- “不是A，不是B，是C”“不快不慢、不轻不重、不冷不暖”等连续否定定义，若一章多次出现，必须删减。
- 抽象名词堆叠（压迫、剥离、终局、失控、沉默、确认）不能替代场面。每个抽象词都要落回一个可见动作或可感后果。

## 去 AI 化规则

### 网文直给优先（新增最高频审查）
- **先保爽感，再保文气**：如果一句话“更文雅”但会削弱冲击力、爽感、推进速度，优先保留更直给的版本
- **能直说就不绕说**：角色想威胁就直接威胁，想翻脸就直接翻脸，想打脸就直接落到动作和结果，不要绕成长句抒情
- **环境描写必须服务剧情**：环境描写只保留能增强气氛、压迫感、危险感、暧昧感、爽点前摇的内容；纯展示文笔的句子删
- **对话必须有推进性**：每段对话至少承担一个功能：推进冲突、释放信息、制造压迫、建立情绪、抬高期待；空转寒暄直接压缩
- **爽点句要短、准、硬**：角色反击、揭穿、翻盘、压人时，优先短句、断句、动词，不要用过多修饰把劲卸掉
- **拒绝“文青式含蓄过度”**：已经到了该摊牌、该爆发、该给读者快感的场景，不要只写眼神、呼吸、沉默，必须落到明确台词或动作
- **网文读感优先于散文感**：如果一句描写更像散文、影视解说、出版文学，而不像连载网文，优先改成更顺口、更快、更易读的表达

### 高频词替换
| AI 高频词 | 替换方向 |
|-----------|---------|
| 不禁 | 删除或用具体动作 |
| 一股（XXX之感）| 直接描述感受 |
| 宛如/仿佛/犹如/像是 | 减少比喻，每段最多1个；严禁连续使用 |
| 映入眼帘 | "看到"或直接描写 |
| 嘴角微微上扬/眼中闪过一丝/心中暗道 | 换成更具体的描写 |
| 极致的/极度的/深深的 | 用具体行为展现程度 |
| 瞳孔骤缩/倒吸一口凉气 | 换新鲜的反应 |
| 散发着/弥漫着 | 直接描写源头 |

### 标点修复
- 紧张场景用句号 → 改感叹号或省略号
- 区分省略号（虚弱/犹豫）和破折号（被打断/声音渐远）
- 不要只用逗号和句号
- 爽点、反击、摊牌句优先短句断开，不要一口气拖成长复句

### 排版检查
- **加粗滥用**：AI 喜欢在情绪词上加粗，人类写作极少这样。除书信/专有名词外删除所有加粗
- **章间重复**：新章禁止复述上章结尾，禁止"承上启下"式总结开头
- **打破第四面墙**：禁止并删除正文中的"第X章"、"上文"、"读者可能记得"等元叙述
- **附加说明清理**：强制删除结尾附加的"【预告说明】"、"敬请期待"、"（第X章完）"等非正文废话
- **重复描写**：同一事物多次详写→保留最简洁的一次


### 润色铁律
- **禁止机械化全局润色** 
- **禁止词藻堆砌** 
- **拒绝浮夸比喻**
- **简化过度文学化表达** 
- 段落长度不要太均匀
- **关键情绪不用藏过头**：该爽就爽，该狠就狠，该疼就疼，该怕就怕，避免“意思到了，但读者没被戳到”
- **高张力场景减少环境占比**：冲突、打脸、揭示、对峙场景里，环境描写不能压过人物动作和台词
- **每段都问一句：这段让读者更想看，还是更想跳？** 后者就删或缩
- **删掉“看起来很会写但其实不推动阅读”的句子**

## 审查输出格式

| 严重级别 | 含义 |
|---------|------|
| 🔴 硬伤 | 角色状态/事实清单矛盾，必须修复 |
| 🟡 软伤 | 逻辑不严密或人设偏移，强烈建议修复 |
| 🟢 微瑕 | 表达或细节问题，可选修复 |

审查后直接输出修复后的完整正文。
