# 阶段 9：弧与支线追踪器（长篇小说专用）

## 使用说明

**每完成一卷（20-50章）后执行一次。** 这是与单章级别的阶段 7（角色状态）和阶段 8（事实清单）互补的**卷级/弧级追踪机制**。

阶段 7 和 8 追踪的是"人"和"事"的细节变化；本阶段追踪的是**叙事线的宏观进展**和**弧的完成度**。

核心理念：**长篇小说最容易出的问题不是某一章写崩了，而是某条线悄无声息地断了、某个弧的核心冲突偏离了方向。这个追踪器就是防止"写着写着不知道在写什么"的锚。**

### 1. 叙事线进展表

为每条叙事线更新当前状态：

| 叙事线 | 全书蓝图中的计划状态 | 实际当前状态 | 偏差说明 | 近期推进摘要 |
|--------|-------------------|------------|---------|------------|

### 2. 叙事线健康检查

逐条检查：
- ❌ 是否有叙事线已连续 **2 卷以上** 处于潜伏状态？（风险：读者遗忘）
- ❌ 是否有叙事线的实际进展与蓝图严重偏离？（风险：结构失控）
- ❌ 是否有叙事线之间应该交叉但实际没有交叉？（风险：割裂感）
- ⚠️ 各叙事线的推进节奏是否平衡？（不要某条线远远跑在前面）

### 3. 当前弧完成度

对照全书蓝图中当前弧的规划，逐项检查：

| 规划项 | 完成状态 | 说明 |

| 弧的核心冲突是否已建立 | ✅/⏳/❌ | |
| 本弧计划引入的角色是否已全部登场 | ✅/⏳/❌ | |
| 本弧的情绪基调是否与计划一致 | ✅/⏳/❌ | |
| 本弧应推进哪些叙事线是否都有进展 | ✅/⏳/❌ | |
| 弧的高潮是否已出现/正在接近 | ✅/⏳/❌ | |

### 4. 跨弧伏笔管理

与阶段 8 的单章伏笔管理不同，这里管理的是**跨越多卷甚至多弧的长线伏笔**：

| 伏笔编号 | 伏笔内容 | 埋设位置 | 预计回收 | 当前状态 | 距离埋设已过章数 |
|---------|---------|---------|---------|---------|--------------|

状态标注：
- 🟢 按计划推进
- 🟡 接近预计回收期（提醒关注）
- 🔴 超期未回收（超过 50 章，需要决定：回收/调整/放弃）

### 5. 下一卷规划建议

基于以上分析，为下一卷提供建议：
- 哪条叙事线应该在下一卷重点推进？
- 是否需要引入新角色？（对照全书蓝图的角色引入计划）

- 情绪节奏上，下一卷应该是什么基调？

---

## 注意事项

1. **卷末追踪是强制检查点**——不要等到弧末才做追踪，那时候已经来不及纠偏
2. **叙事线健康检查是最核心的功能**——它能在问题变严重之前预警
3. **跨弧伏笔与阶段 8 的伏笔管理是两层**——阶段 8 管单章级（5-10 章回收），这里管弧级（几十到上百章回收）
4. **弧末清算必须做**——这是调整后续规划的唯一窗口，错过了就只能硬着头皮往下写
5. **追踪表不需要覆盖每一个细节**——它是宏观视角，细节留给阶段 7 和 8
6. **蓝图修订要谨慎**——频繁修改蓝图说明初始规划不够充分，建议在弧的前 1/3 就确定方向
