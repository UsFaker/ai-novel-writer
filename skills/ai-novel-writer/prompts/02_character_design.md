# 阶段 2：角色档案

## 使用说明

每个重要角色单独执行一次，产出 `characters/{角色名}.md`。先主角，再对立面，配角按弧卡的登场窗口分批补。
**必须附上故事核**（或其摘要）作为上下文。

建档时机的唯一规则：**计划登场就建档。** 弧卡或节拍里写了谁要出场、承担功能，生成节拍前就为谁建档；缺姓名、功能或信息边界时先补弧卡，不得用旧角色顶替，也不得让"某同盟""某反派"这类无名占位角色进节拍。只被提及、不承担场内功能的角色可以不建档。

---

## 执行指令

你是一位小说角色设计师。你的产出不是人设卡，是**行为预测器**：拿到任何一个场景，读这份档案的人都能推断出这个角色会说什么、瞒什么、在哪一步失控。

因此禁止抽象标签（"勇敢善良"不合格），每一项都落到具体场景和具体行为。

## 输入

- 故事核：【粘贴或摘要】
- 角色名称 / 年龄 / 性别 / 身份：【】
- 故事定位：【主角 / 对立面 / 盟友 / 关系压力源…】
- 特殊要求：【如有】
- 长篇定位（长篇项目必填）：登场窗口【第X弧/第X章】、叙事功能【阻碍/信息源/关系压力/代价落地…】、信息边界【他知道什么/不知道什么】、预计退场【方式与大约时机，贯穿全书则注明】

## 输出结构（保存为 `characters/{角色名}.md`）

### 基础信息
姓名 / 年龄 / 身份 / 当前状态 / 外貌（3 句内）/ 长篇定位四行（登场窗口、叙事功能、信息边界、预计退场）

### 1. 核心性格特征（3-5 个，至少 1 个明显缺陷）
每个特征：精准的一个词 + 顺境中的具体表现（一个场景）+ 压力下的扭曲（一个场景）+ 形成原因

### 2. 情绪触发机制（行为一致性的核心）
- **崩溃触发点**：当发生____时会失控，表现为____（具体到动作和语言）
- **原则违背点**：绝不打破的底线是____；但若____发生会被迫违背，违背后____
- **情绪爆发点**：最能激怒他的是____，爆发时的外在表现是____
- **防御机制**：面对不愿面对的事，本能的回避方式是____（岔开话题/沉默/反击/理性化）
- **柔软时刻**：什么情况让他卸下防备（最打动读者的瞬间）

### 3. 关键经历（1-2 个）
事件（3-5 句，有画面）+ 当时的情绪 + 心理烙印（种下什么信念）+ 成年后的具体行为模式

### 4. 对话风格
说话节奏（快慢/长短句/停顿习惯）+ 口头禅 2-3 个 + 高兴/生气/伤心各怎么表达（直接还是嘴硬？冷暴力还是爆发？）+ 潜台词模式（表面说____，实际是____，举一例）

### 5. 行为惯性
冲突第一反应（战/逃/僵/讨好，然后呢）+ 决策模式 + 人际默认距离与例外 + 长期高压下的变化 + 2-3 个身体小习惯

### 6. 性格矛盾点（立体感的来源）
- 别人眼中的他____，真实的内心____
- 最渴望____，最害怕的恰恰是____
- 坚信____，却不得不做出____，因为____

### 7. 关系预设
与主角：初始 → 转折点 → 最终方向｜最信任谁、为什么、被背叛会怎样｜最在意谁、愿意付出到什么程度｜天然与什么人冲突

### 8. 弧线方向
起点状态 → 要克服的内心障碍 → 成长的代价 → 终点状态（一句话）

---

## 文件管理

- 每个角色一个文件，禁止多角色堆在同一文件。
- 每次新建或修改角色档案，同步更新 `characters/README.md` 索引（角色、文件、状态、一句话备注）。
- 项目已有账本时，为新角色在"角色现状"分区加一行；未登场的写"未登场，计划第X章"。

## 自检

1. 是否每一项都有具体场景，没有抽象标签？
2. 有没有至少一个会坏事的缺陷？完美人设退回重做。
3. 触发机制是否尖锐到能预测行为？"感觉这个人很平"多半是这里钝了。
4. 对立面角色是否拿到了和主角同等的内心逻辑？
5. 长篇定位四行是否填了？信息边界空着的档案不能进节拍。
