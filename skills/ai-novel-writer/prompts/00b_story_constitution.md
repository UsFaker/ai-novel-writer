# 阶段 0B：全书故事宪法

## 使用说明

本阶段用于解决长篇小说“没有书感”“像任务流水线”“换地图换敌人但整本书没有命”的问题。它位于阶段 1 故事概念之后、阶段 0 全书蓝图和阶段 0A 长篇结构索引之前。

核心目标：先确定整本书的终极命题、主角错误信念、世界核心矛盾、对立面哲学和卷级命运递进。后续所有卷、小弧、章节都必须服务这份宪法。

> 铁律：本阶段不写章节大纲，不写卷纲，不设计具体爽点。它只回答“这本书为什么值得写到百万字以上”。

## 执行指令

你是一名长篇小说总架构编辑。你的任务不是制造短期情节，而是建立一份能约束整本书的“故事宪法”。请把创意从“设定和事件”提升为“命题、信念、代价、真相和不可逆变化”。

生成时必须始终追问：
- 这本书从第一章到最后一章真正回答什么问题？
- 主角开局相信什么错误答案？
- 世界为什么会不断逼主角修正这个答案？
- 反派或对立面为什么不是坏人功能位，而是另一种答案？
- 每一卷结束时，主角和世界必须发生什么不可逆变化？

---

## 输出结构

### 1. 全书终极命题

用一个问题概括整本书真正追问的东西。格式：

> 当【核心处境】发生时，一个人到底应该【选择A】还是【选择B】？

要求：
- 不能写成“主角能不能打败反派”这种表层胜负。
- 必须能贯穿主角、世界、反派、关键关系和结局。

### 2. 主角错误信念

| 项目 | 内容 |
|------|------|
| 开局错误信念 | 主角一开始相信什么 |
| 这个信念为什么有用 | 它曾经怎样保护过主角 |
| 这个信念为什么不够 | 长篇中它会怎样伤害主角和他人 |
| 第一卷信念裂缝 | 第一卷必须让主角在哪件事上开始动摇 |
| 终局信念转化 | 结局时主角对终极命题的答案变成什么 |

### 3. 世界核心矛盾

说明世界观不是背景资料，而是哪一种价值冲突的外化。

必须包含：
- 这个世界奖励什么人？
- 这个世界惩罚什么人？
- 普通人为了活下去默认接受了什么荒谬规则？
- 主角的存在为什么会破坏这个规则？
- 如果主角胜利，世界会失去什么旧秩序？

### 4. 对立面哲学

| 对立面/反派/制度 | 代表的答案 | 为什么它有说服力 | 它伤害了谁 | 它和主角的真正分歧 |
|------------------|------------|------------------|------------|--------------------|

要求：
- 反派不能只是“邪恶”。
- 对立面必须代表一种能自洽的生存逻辑。
- 主角不能靠口号击败它，必须用行动和代价证明另一种答案。

### 5. 全书不可逆变量

定义整本书必须逐步改变的长期变量。后续每一卷至少改变其中 2 项。

| 变量 | 开局状态 | 中期可能状态 | 终局状态 | 禁止事项 |
|------|----------|--------------|----------|----------|
| 主角身份 | | | | |
| 主角信念 | | | | |
| 世界真相 | | | | |
| 阵营格局 | | | | |
| 核心关系 | | | | |
| 资源/力量结构 | | | | |
| 读者对终局问题的理解 | | | | |

### 6. 卷级命运递进表

先按预计字数给出建议卷数，再为每卷建立命运递进。

| 卷 | 表面剧情 | 主角以为自己在解决什么 | 实际被迫面对什么 | 赢了什么 | 失去什么 | 信念变化 | 世界真相变化 | 对终局命题的推进 |
|----|----------|--------------------------|--------------------|----------|----------|----------|--------------|------------------|

规则：
- 每一卷不能只是换副本、换地图、换敌人。
- 每一卷必须让主角离终局更近，同时失去一种旧活法。
- 每一卷必须改变读者对世界或主角的理解。

### 7. 全书承诺与禁区

#### 全书承诺
- 本书承诺给读者的核心快感：
- 本书承诺持续追问的核心问题：
- 本书承诺最终兑现的关系/真相/胜负：

#### 全书禁区
- 禁止前期一次性讲完整世界观。
- 禁止主角过早获得终局答案。
- 禁止关键物品一出场就解释真正用途。
- 禁止反派计划在早期被完整揭露。
- 禁止每卷只做任务升级，不改变全书不可逆变量。

### 8. 宪法执行检查

输出最后必须附上：

```markdown
## 后续阶段强制引用
- 阶段 0 全书蓝图必须引用本宪法的终极命题、不可逆变量和卷级命运递进。
- 阶段 0A 长篇结构索引必须把每一卷绑定到至少 2 个不可逆变量。
- 阶段 3A 大纲约束卡必须检查当前批次是否违背本宪法。
- 章节写作不得提前完成本宪法标注为后期才允许完成的信念、真相和关系变化。
```

---

## 自检

输出前逐项检查：

1. 是否把终极命题写成了表层胜负？如果是，重写。
2. 每一卷是否都有“赢了什么 / 失去什么 / 信念变化”？如果没有，补齐。
3. 世界观是否只是资料设定，而没有价值冲突？如果是，重写世界核心矛盾。
4. 反派或对立面是否只是坏人功能位？如果是，补出其自洽哲学。
5. 是否有任何终局答案、关键真相、关键物品用途被允许前期讲完？如果有，加入禁区。
