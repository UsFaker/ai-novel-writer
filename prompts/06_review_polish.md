# 阶段 6：审查与润色

## 使用说明

章节正文生成后，使用本阶段的提示词进行全面审查和润色。
**这是最不可省略的环节**——第一遍生成的内容永远是半成品。

建议按以下顺序执行四轮审查：
1. 一致性审查（人设 + 逻辑）
2. 质量润色（对话 + 描写）
3. 去 AI 化处理
4. 错别字与语病校对

---

## 提示词模板 A：一致性审查

```
你是一位严格的小说编辑，负责检查章节内容的一致性。你手握角色档案、动态状态表和累积事实清单三把尺子，任何与这三份文档矛盾的内容都是必须修复的BUG。

## 角色档案
【粘贴所有相关角色档案】

## ⚠️ 角色状态快照（来自阶段7）
【粘贴最新的角色状态表，重点关注：存活状态、当前位置、已知信息、持有物品】

## ⚠️ 累积事实清单（来自阶段8）
【粘贴最新的累积事实清单，重点关注：生死事实、物品归属、待回收伏笔、时间线】

## 本章正文
【粘贴需要审查的章节正文】

## 前后文参考
- 上一章结尾：【粘贴上一章最后 2-3 段】

## 审查清单

请逐项检查并报告问题：

### 1. 角色行为一致性
- 每个角色的行为是否符合角色档案中的设定？
- 角色的情绪反应是否和触发机制匹配？
- 角色的对话风格是否和档案设定一致（口头禅、节奏、表达方式）？
- 标注所有不一致的地方，并给出修改建议

### 2. 🔴 角色状态校验（对照状态表逐项核实）
- 本章是否让已死亡角色以活人身份出场？
- 角色的位置是否与状态表中的"当前位置"矛盾？（不能凭空从A地瞬移到B地）
- 角色是否使用了他不应该知道的信息？（对照"已知信息"和"不知道的关键信息"）
- 角色是否使用了他已经失去的物品/能力？
- 角色之间的关系互动是否与状态表中的"与主角关系"方向一致？
- **此项为最高优先级审查项——任何违反都是硬伤BUG**

### 3. 🔴 事实清单校验（对照累积事实清单逐项核实）
- 本章是否与任何已记录的"生死事实"矛盾？
- 本章是否与任何已记录的"物品/能力变动"矛盾？
- 本章是否与任何已记录的"身份/关系变动"矛盾？
- 时间线是否与累积时间线吻合？（如：三天期限写着写着变成一周）
- **此项为最高优先级审查项——任何违反都是硬伤BUG**

### 4. 伏笔追踪校验
- 本章节奏约束中要求"应回收的伏笔"是否已经在正文中体现？
- 本章节奏约束中要求"必须埋设的伏笔"是否已经在正文中植入？
- 是否有超期未回收的伏笔需要预警？（超过 5 章未回收的伏笔应标黄提醒）

### 5. 情节逻辑自洽
- 本章是否有和前文矛盾的地方？
- 因果链是否完整？（事情发生是否有充分的原因）
- 时间线是否合理？
- 空间逻辑是否通顺？（如：角色不能瞬间出现在不同地方）
- 标注所有逻辑漏洞，并给出修复建议

### 6. 信息一致性
- 角色知道的信息是否和前文一致？（不能突然知道不应该知道的事）
- 设定细节是否和前文一致？（如名字、外貌、能力、地名等）
- 标注所有信息错误

## 输出格式

| 问题编号 | 严重级别 | 问题类型 | 位置 | 问题描述 | 修改建议 |
|---------|---------|---------|------|---------|---------||

严重级别说明：
- 🔴 **硬伤**：角色状态/事实清单矛盾（必须立即修复）
- 🟡 **软伤**：逻辑不严密或人设偏移（强烈建议修复）
- 🟢 **微瑕**：表达或细节问题（可选修复）

最后给出一个总体评价：本章一致性评分（1-10）和最需要优先修改的 3 个问题。
```

## 提示词模板 B：质量润色

```
你是一位文字功底深厚的小说润色编辑，你的目标是让文字更有力量、对话更真实、叙事更紧凑。

## 本章正文
【粘贴需要润色的章节正文（已通过一致性审查）】

## 本章情绪目标
- 主导情绪：【从情绪节拍表取】
- 情绪强度：【1-10】

## 润色要求

### 1. 对话润色
- 检查对话是否有潜台词层次（不能全是直白表达）
- 检查对话节奏（不能全是长句或全是短句）
- 删除不必要的对话标签（"他说"、"她说"不需要每句都有）
- 改善对话周围的动作描写——用动作代替对话标签
- 示范改写法：
  - 原文："我没事。"她说，语气平淡。
  - 改后：她低头整理杯子，手指在杯沿上转了一圈。"没事。"

### 2. 叙述润色（极其重要：去油腻化与去机械化）
- **禁止机械化地全局句句润色**：不要觉得每句话都需要“优化”。初稿中那些干脆利落、原始且有冲击力的短句，**必须原封不动地保留**。机械地为每个名词加形容词是破坏节奏的致命伤。
- 只有在原文表达不清、情感不到位或节奏拖沓时，才允许进行润色修改。
- 删除所有不推动情节或不服务情绪的段落
- 将"告诉型"描写改为"展示型"描写
  - 原文：他很紧张。
  - 改后：他的手指在桌下交握，指节发白。
- **绝对禁止词藻堆砌**：不要在一个名词前叠加超过2个修饰词（如：绝对禁止出现类似"极为高贵圣洁脱俗的白衣"这种写法，直接写"白衣纤尘不染"即可）。
- **拒绝过度生僻/浮夸的比喻**：比喻要贴近生活和直觉，不要动辄"九幽星辰"、"昆仑玄冰"、"万古深渊"。这会让文章显得极度悬浮和AI味。
- 检查段落长度——网文段落不宜超过 5 句
- 检查节奏——高紧张度段落要用短句，低紧张度可以适当放慢

### 3. 情绪强化
- 检查本章的情绪强度是否达到了目标值
- 如果情绪不够强烈，建议在哪里加强（增加什么样的描写或对话）
- 如果情绪过于直白，建议如何含蓄处理
- 检查章末钩子是否足够有力

### 4. 删减建议
- 标出所有可以删除而不影响故事的段落或句子
- 标出所有重复表达的地方
- 标出所有节奏拖沓的地方

## 输出格式

1. 先输出润色后的完整正文
2. 在正文之后附上修改说明：列出所有主要修改及理由
```

## 提示词模板 C：去 AI 化处理

```
你是一位反 AI 检测专家，你的任务是让这段文本读起来完全像是人类写的。

## 本章正文
【粘贴经过一致性审查和质量润色后的正文】

## 去 AI 化要求

### 1. 高频 AI 词汇替换

检查并替换以下 AI 喜欢用但人类作者很少密集使用的词汇：

| AI 高频词 | 建议替换方向 |
|-----------|------------|
| 不禁 | 删除，或用具体动作代替 |
| 一股（XXX之感）| 直接描述感受，不要用"一股" |
| 宛如 / 仿佛 / 犹如 | 减少比喻，每段最多1个；或换成"像"、"跟" |
| 映入眼帘 | 换成"看到"、"注意到"或直接描写 |
| 嘴角微微上扬 | 换成其他表达笑意的方式 |
| 眼中闪过一丝 | 换成更具体的眼神描写 |
| 心中暗道 | 换成直接的心理活动或删除 |
| 脸上露出 | 直接描写表情 |
| 不由得 | 删除或改写 |
| 缓缓说道 | 换成具体的说话方式 |
| 微微一笑 | 换成具体的笑法 |
| 深吸一口气 | 适量使用，不要频繁出现 |
| 极致的/极度的/深深的 | 减少此类程度副词的滥用，用具体行为展现程度 |
| 瞳孔骤缩/倒吸一口凉气 | 找点新鲜的惊人反应，比如"指甲死死抠进肉里" |
| 散发着/弥漫着 | 直接描写源头，少用这种抽象动词 |
| 华丽/绝美/不可名状 | 用符合角色视角的白话来形容，主角是泥腿子就用泥腿子的词汇库 |

### 2. 句式多样化
- 检查是否有重复的句式结构
- "主语 + 动词 + 宾语"的简单句不要连续出现超过 3 句
- 增加倒装句、省略句、感叹句等变化
- 对话中加入不完整的句子（真人说话经常说到一半就不说了）

### 3. 不完美化处理
- 适当加入1-2处略微口语化的表达
- 对话中可以有1处轻微的"说错话"或"词不达意"
- 叙述中可以有1处略带主观偏见的描写（人类作者会有自己的倾向性）

### 4. 节奏打破
- 检查是否有"太整齐"的排比或对仗——适当打破
- 段落长度不要太均匀——有长有短才自然
- 如果连续 3 段都是差不多的长度，调整其中一段

## 输出格式

输出去 AI 化处理后的完整正文。
在文末附上：处理了多少处，主要修改类型统计。
```

## 提示词模板 D：错别字与语病校对

```
你是一位极其细心的文字校对员。你的任务是通读给定的文本，找出所有错别字、标点错误以及明显的语病。

## 本章终稿
【粘贴经过前三轮处理后的最终正文】

## 校对要求

1. **错别字排查**：
   - 重点检查同音错别字（如：“一幅面孔”应为“一副面孔”、“副词”而非“幅词”等）。
   - 检查形近字混淆（如：“己”和“已”、“戊”和“戌”等）。
2. **标点符号验证**：
   - 检查全半角标点混用问题。
   - 检查对话引号是否成对闭合。
   - 保证逗号、句号、感叹号、省略号的使用符合中文排版规范。
3. **基础语病修正**：
   - 检查是否有漏字、多字导致的句子不通顺。
   - 不要改变原句修辞风格，只修正常识性语法错误。
4. **格式排查**：
   - 绝对禁止在系统提示等方括号语句（如【xxxxx】）前加 `>` 引用符号，发现后必须全部删除。

## 输出格式

1. 如果没有发现错误，请直接回答：“✅ 校对通过，未发现错别字或语病。”
2. 如果发现错误，请列出修改清单：

| 原句位置/内容 | 错误形式 | 修改建议 |
|--------------|---------|---------|

3. 在清单下方，输出修订后的**干净且完整的纯文本正文**，以便作者直接复制使用。
```

---

## 注意事项

1. **四轮审查的顺序不能颠倒**——先保证一致性和逻辑正确，再润色文字，接着去 AI 味，最后才能做错别字校对，以免前面修改引入新错误。
2. **一致性审查是最重要的**——人设崩塌和逻辑漏洞是读者弃书的首要原因
3. **去 AI 化不能只靠 AI**——最终必须自己通读一遍，融入个人表达风格
4. **不要期望一次审查就完美**——可以针对特定问题多次迭代
5. **保留修改记录**——方便回顾什么类型的问题出现最多，逐步改进指令
