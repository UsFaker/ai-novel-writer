# 阶段 3B：批次上下文包

## 使用说明

本阶段位于阶段 3A 大纲约束卡之后、阶段 3 情绪节拍大纲之前。它的任务不是写节拍，而是把全书资产过滤成当前 10-20 章可用的安全输入。

核心原则：**全书资产是数据库，不是写作输入。** 生成情绪节拍时只允许使用本文件产出的批次上下文包，禁止复制全书资产原文，禁止把卷级、书级、后续批次事件带进当前批次。

---

## 输入材料

只在制作本包时读取以下文件，读取后必须降级为权限摘要，不得照搬原文：

- `concept.md`
- `outlines/长篇结构索引.md`
- `outlines/全书故事宪法.md`
- `outlines/全书关键资产库.md`
- 角色状态表、累积事实清单、故事线事件追踪表、伏笔索引
- 上一批节拍接力卡（如存在）

---

## 任务

请为【当前卷段 / 当前小弧 / 当前章段批次】生成一份 `批次上下文包`，保存为 `outlines/批次上下文包_第X-Y章.md`。

## 输出格式

### 1. 批次定位

| 项目 | 内容 |
|------|------|
| 当前阶段/篇 | |
| 当前卷 | |
| 当前卷段 | |
| 当前小弧 | |
| 当前章段批次 | |
| 章节范围 | |
| 本批次任务 | |
| 批次末状态 | |
| 下一批入口 | |

规则：
- 当前卷段用于承接超长卷；如果一卷超过 150 章，必须先拆卷段，再生成批次上下文包。
- 下一批入口只能作为章末钩子、悬念或过渡承接，不能写成本批次已经发生的核心行动、结果变化或批次末状态。

### 2. 当前批次权限三栏

#### 允许写
- 只列当前批次可以正面发生的事件、关系变化、资源变化、信息变化。

#### 只能暗示
- 只列当前批次可以以影子、异常、误判、传闻、残片、反应出现的内容。
- 这些内容不能被解释、不能被正确使用、不能完成阶段目标。

#### 禁止写
- 列出当前批次绝对不能发生、不能解释、不能回收、不能提前兑现的内容。
- 必须包含后续批次、小弧、卷段、卷、全书高潮中容易被提前写完的事件。

### 3. 故事线下一步动作

| 故事线 | 当前状态 | 本批次允许动作 | 本批次禁止动作 | 下次推进窗口 | 最长沉默阈值 |
|--------|----------|----------------|----------------|--------------|--------------|

规则：
- 只写故事线下一步动作，不粘贴完整事件序列。
- 如果完整事件序列中包含后续爆点，只能降级成“禁止写”或“只能暗示”。
- 每条活跃故事线必须说明本批次是推进、回声、潜伏、转折、收束还是冻结。

### 4. 伏笔状态机

| 伏笔 | 当前状态 | 本批次允许处理 | 禁止处理 | 计划回收窗口 |
|------|----------|----------------|----------|--------------|

伏笔状态只能使用：
- 未埋
- 可埋
- 已埋-不可解释
- 可回声-不可解释
- 可局部回收
- 可完整回收
- 已回收
- 冻结
- 废弃

规则：
- `可埋` 只能制造问题，不能给答案。
- `已埋-不可解释` 和 `可回声-不可解释` 只能提醒读者，不得解释。
- 只有 `可局部回收` 或 `可完整回收` 才能进入情绪节拍的结果变化。

### 5. 关键资产权限摘要

| 资产 | 当前解锁层级 | 本批次允许写法 | 本批次禁止写法 | 谁知道/谁不知道 | 下次允许推进窗口 |
|------|--------------|----------------|----------------|------------------|------------------|

规则：
- 禁止复制全书资产原文。
- 只输出当前批次需要的权限摘要。
- 不能出现资产的完整来源、真正用途、终局功能和后期正确用法，除非当前批次明确允许。

### 6. 角色与信息差摘要

| 角色 | 本批次功能 | 已知信息 | 不知道的信息 | 行动边界 |
|------|------------|----------|--------------|----------|

规则：
- 只列本批次会用到的角色。
- 角色不知道的信息不能进入其台词、判断或主动行动。

### 7. 节奏护栏

- 本批次起始情绪：
- 本批次中段压力：
- 本批次末尾情绪：
- 本批次小高潮允许范围：
- 禁止完成的卷级/书级高潮：

### 8. 节拍接力卡

情绪节拍生成完成后，必须把以下字段补全，作为下一批上下文包输入：

| 项目 | 内容 |
|------|------|
| 本批已完成 | |
| 本批未完成 | |
| 新增伏笔 | |
| 回声但未解释的伏笔 | |
| 已回收伏笔 | |
| 活跃故事线新状态 | |
| 关键资产最新层级 | |
| 下一批入口 | |
| 下一批禁止提前完成 | |

---

## 自检

输出前逐项确认：

1. 是否只输出当前批次可用信息，没有复制全书资产原文。
2. 是否把未来事件放入“只能暗示”或“禁止写”，而不是放入“允许写”。
3. 是否为每条活跃故事线给出下一步动作，而不是完整事件序列。
4. 是否为每个伏笔标注伏笔状态机状态。
5. 是否为每个关键资产给出权限摘要和禁止写法。
6. 是否明确下一批入口只能作为钩子。
