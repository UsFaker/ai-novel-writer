# 阶段 8：章节事实清单提取

## 使用说明

**每完成一章的终稿后，必须与阶段 7（角色状态更新）同步执行本阶段。** 

本阶段的产出是一份**章节事实清单**，用于记录本章中确立的所有"硬事实"——即不可逆转的、后续章节必须遵守的客观事件。

核心理念：**事实清单是小说的"账本"。每一章的剧情都是在往账本上记账，后续章节不能篡改已记录的账目。**

与阶段 7（角色状态表）的区别：
- 角色状态表关注的是**"人"**——角色的最新状态
- 事实清单关注的是**"事"**——已经发生的不可逆事件

---

## 提示词模板

```
你是一位极度严谨的小说连续性检查员，你的任务是从每一章中提取所有"已成立的硬事实"，确保后续创作不会与已有事实矛盾。

## 本章终稿正文
【粘贴刚刚完成的章节终稿全文】

## 前序章节累积事实清单
【粘贴之前所有章节的累积事实清单。如果是第一章，写"无"】

## 任务

请从本章正文中，逐一提取以下类别的硬事实，并追加到累积清单中。

## 事实分类与提取规则

### 1. 🔴 生死事实（最高优先级）
- 谁在本章死亡？死因是什么？有无目击者？
- 谁在本章重伤？伤的是哪里？会影响后续行动吗？
- **规则：已死亡的角色在后续章节中绝不能再以活人身份出场（回忆/闪回除外，且必须明确标注为回忆）**

### 2. 🟠 物品/能力变动
- 谁获得了什么物品/能力？来源是什么？
- 谁失去了什么物品/能力？原因是什么？
- 物品的已知属性/限制是什么？

### 3. 🟡 身份/关系变动
- 谁的身份发生了变化？（如：从杂役升为弟子）
- 哪些角色之间的关系发生了不可逆转的变化？
- 有无新的结盟/反目/背叛事件？

### 4. 🔵 信息/秘密揭示
- 本章揭示了什么之前未知的信息？
- 哪些角色知道了这个信息？哪些角色仍不知道？
- 有无新的谎言或误导被植入？

### 5. 🟢 伏笔管理
- **新埋设的伏笔**：本章埋下了什么新的悬念/暗示？（记录具体内容和位置）
- **已回收的伏笔**：本章是否回收了之前积累的伏笔？（标注来源章节）
- **应回收未回收的伏笔**：哪些伏笔按节奏应该在本章回收但没有？（标注提醒）

### 6. ⚪ 时间线与空间
- 本章的时间跨度是多少？（如：从第三天傍晚到第三天深夜）
- 截至本章结束，故事总时间线推进到了什么时候？
- 本章出现了什么新的地点/场景？有无空间矛盾？

```

- [事实编号] 具体描述

### 🟠 物品/能力变动

- 本章时间跨度：
- 累积时间线：
```

最后，将本章事实追加到累积清单末尾，并输出完整的累积清单。
```

---

## 注意事项

1. **事实清单是"只增不改"的**——已经记录的事实不能删除或修改，只能追加新事实
2. **生死事实是最高优先级**——写入"某角色已死亡"后，后续任何章节都必须遵守
3. **伏笔管理极其重要**——这是网文读者最敏感的地方，埋了伏笔不回收 = 挖坑不填 = 弃书
4. **时间线要精确**——修仙小说尤其容易出现"三天时限"写着写着变成一周的BUG
5. **每个事实都要编号**——方便后续引用（如"参见事实 #F3-02"表示第3章第2条事实）
6. **事实清单 + 角色状态表 = 后续章节的"铁律"**——生成新章节时必须同时参考这两份文档
