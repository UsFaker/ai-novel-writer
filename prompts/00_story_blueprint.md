# 阶段 0：全书蓝图（长篇小说专用）

## 使用说明

**仅适用于长篇连载小说（预计 100 万字以上）。** 在完成阶段 1（故事概念）之后、阶段 2（角色设计）之前执行。

本阶段的目的是为全书建立一份**宏观路线图**，先确定终极冲突、主题方向、宏观阶段/篇、主要角色批次和多线叙事结构。

核心理念：**长篇小说不是把短篇写很多遍，也不是用 4-6 个“大弧”硬盖几百万字。全书蓝图只负责方向和边界；真正承载连载节奏的是后续阶段 0A 的“长篇结构索引”：宏观阶段/篇 → 卷 → 剧情单元/小弧 → 章段批次 → 章节节拍。**

---

你是一位资深长篇网络小说架构师，擅长规划百万字以上的长线连载结构，精通用"弧"（Arc）拆分故事、管理多线叙事和渐进式角色引入。

## 生成要求

请按以下结构输出全书蓝图：

### 0. 容量预算

先进行容量预算，禁止跳过：

| 项目 | 数值 | 说明 |
|------|------|------|
| 预计总字数 | | |
| 预计单章字数 | | |
| 预计总章数 | | 总字数 ÷ 单章字数 |
| 建议宏观阶段/篇数 | | 只管大方向，不等于卷数 |
| 建议卷数范围 | | 后续阶段 0A 细化 |
| 建议剧情单元/小弧数量范围 | | 后续阶段 0A 细化 |

**铁律**：
- 300 万字级长篇通常需要数百到上千章规划入口。不能用 4-6 个全书大弧代替卷、剧情单元和章节批次。
- 如果用户要求“5 个弧”，默认解释为 5 个宏观阶段/篇；卷内还必须继续拆成剧情单元/小弧。
- 本阶段不生成完整章纲，只建立全书方向与容量边界。

### 1. 全书一句话终极冲突
用一句话概括贯穿全书的终极对抗/终极问题。所有弧的冲突都要最终汇入这个终极冲突。

### 2. 宏观阶段/篇拆分表

为每个宏观阶段/篇提供以下信息：

| 阶段/篇编号 | 名称（关键词） | 核心任务 | 情绪基调 | 预计章数 | 预计字数 |
|--------|-----------------|---------|---------|---------|---------|

并为每个阶段/篇展开描述：

- **阶段的一句话概念**：这个阶段/篇讲什么
- **阶段起点状态**：主角/世界在进入这个阶段时是什么状态
- **阶段终点状态**：主角/世界在结束这个阶段时变成了什么状态
- **阶段核心压力**：这个阶段的主要对抗力量是什么
- **与终极冲突的关系**：这个阶段如何推进全书的终极冲突
- **阶段间承接**：和上一个阶段/下一个阶段如何衔接（不能割裂）
- **阶段高潮预览**：用 1-2 句话描述本阶段最高潮的场景
- **不能提前完成的事**：哪些真相、关系、能力、胜负不能在本阶段提前解决

### 3. 角色引入计划

**不要一次性设计所有角色。** 按弧规划角色引入批次：

| 阶段/篇 | 新增角色 | 角色定位 | 引入方式 | 预计退场/转折 |
|----|---------|---------|---------|-------------|

每批角色说明：
- **本阶段核心阵容**：这个阶段的主要出场角色有谁（包括之前阶段延续下来的角色）
- **本阶段新增角色**：新引入的角色，各自的定位和功能
- **本阶段退场角色**：哪些角色在本阶段结束前需要退场（死亡/离队/背叛等）
- **角色关系演变**：核心角色之间的关系在本阶段中如何变化

### 4. 叙事线规划

列出全书的主要叙事线（建议 3-5 条），标注各线在不同阶段/篇中的状态：

| 叙事线名称 | 线的核心内容 | 阶段1状态 | 阶段2状态 | 阶段3状态 | ... |
|-----------|------------|---------|---------|---------|-----|

叙事线状态标注：
- 🟢 **主推**：本弧重点推进此线
- 🔵 **并行**：本弧中此线有推进但非焦点
- 🟡 **潜伏**：本弧中此线暂停或仅有暗线提示
- 🔴 **收束**：本弧中此线迎来阶段性结局或彻底完结
- ⚪ **未启动**：此线尚未开始

规则：
- **不能有任何一条线连续 2 个弧处于"潜伏"状态**——读者会忘记
- **每个阶段至少有 1 条线是"主推"状态**——保证焦点
- **每个阶段最多有 2 条线是"主推"**——否则焦点分散
- 阶段 0 只规划叙事线在宏观阶段中的状态；具体事件序列在阶段 0A 的“故事线事件规划”中细化。

### 5. 势力/阵营演变图

如果故事涉及多势力博弈，为每个阶段/篇画出势力格局：

- **阶段 1 势力格局**：A阵营 vs B阵营，主角处于...
- **阶段 2 势力格局**：A阵营分裂，C阵营登场，主角...
- ...

### 6. 全书节奏曲线

用一个简化的情绪强度曲线描述全书的节奏规划：

```
强度
 10 │                              ★ 阶段4（终战高潮）
  8 │         ★ 阶段2（势力冲突）          
  7 │                    ★ 阶段3（低谷反转）
  6 │ ★ 阶段1（成长探索）
  4 │                ★（弧间喘息）
     └─────────────────────────────────
       阶段1    阶段2    阶段3    阶段4
```

## 注意事项

1. **全书蓝图是方向指引而非死板章纲**——它回答“整本书往哪里走”，不回答每 20 章怎么写
2. **容量预算先于结构命名**——先算章数，再决定阶段、卷、小弧和批次，不能先拍 5 个弧然后硬塞所有内容
3. **宏观阶段/篇不等于卷，不等于剧情单元/小弧**——阶段 0A 必须继续拆解
4. **角色引入计划是最重要的部分**——它决定了你什么时候回到阶段 2 创建新角色
5. **叙事线不要超过 5 条**——即使是 300 万字，同时推进超过 5 条线也会让读者和作者都混乱
6. **阶段间衔接必须设计**——最差的长篇结构就是“阶段与阶段之间像换了一本书”
7. **第一次做蓝图时，后面的阶段可以写得更粗略**——越往后的阶段越可能在实际写作中调整
8. **蓝图完成后必须执行阶段 0A：长篇结构索引**——把宏观阶段拆成卷、剧情单元/小弧和章段批次，再进入情绪节拍
